גרסה	מה השתנה
V1.1–V1.3
אין קובץ בפרויקט
V1.4
מספר פצצה, רשימת מטרות עם זמן ירי, ומחוון וקטורי
V1.5
רשימת המטרות נפתחת כתפריט נגלל קצר
V1.6
זמן ירי והוספה בתוך התפריט. רשימת המטרות עם היסטוריית תיקונים הוסרה
V1.7
שם ונ"צ נשמרים מתוך התפריט יחד עם זמן הירי
V1.8
מגבלות 400 מ׳ ו־550 מ׳ גם בתיקון וקטורי
V1.9
שם, נ"צ, זמן ירי והוספה או מחיקה רק בתוך הרשימה
V1.10
מטרה פעילה, רשימה אחת עם טיווח, פירוט חריגה, וגרסה בדיווח
V1.11
נ"צ תמיד גלוי, תג מטרה, שפה בהגדרות, ומחיקת כל הנתונים
V1.12
כפתור ירוק «פגיעה» עם סיכום לוואטסאפ. «שתף דיווח» הוסר
V1.13
נ"צ המטרה והפגיעה ממורכזים בשדה
V1.14
התאמה לאייפון ולעבודה בלי רשת מיד בעליית הדף
V1.15
הורדה ישירה של הקובץ, ואותה התאמה גם לאנדרואיד
V1.16
באייפון קישור נפתח בספארי. קובץ מהקבצים מציג שהמחשבון לא רץ שם
V1.17
פקודת תיקון וקטורי במדריך, ו«מטוויח» אחרי «7 כאן»
V1.18
«הוסף לדף הבית» בראש ההגדרות, מתחתיו המדריך, וטקסט גדול יותר
V1.19
התראת דף הבית בהפעלה הראשונה ובראש המדריך. פורמט ה־Excel ירד לסוף. «עקב חריגה מרדיוס בטיחות»
